Project support

Help us diagnose the problem.

JSForm is beta software. Clear reports help improve the framework for everyone.

Use the JSForm issue tracker.
Search existing reports first, then open a new issue when the problem has not already been recorded.

Include these details

  • What you were trying to do
  • What happened and what you expected
  • The JSForm and Python versions
  • Steps that reliably reproduce the problem
  • The generated support log, with sensitive information reviewed before sharing

Before sharing a log

Review it for names, database addresses, file paths, or application-specific information that should remain private. Never include passwords or database credentials.
